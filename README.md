# O.CUBE Asset Management Limited — Official Web Application

Production-ready Next.js 14 web application designed for **O.CUBE Asset Management Limited** (RC 1247860, Incorporated in Nigeria).

---

## 🚀 Features Built

1. **Interactive 3D Geometry**: Custom pure-CSS 3D rotating & interactive **O.Cube** model with perspective rendering, barcode/QR faces, and touch/drag controls.
2. **Dynamic Hero Slideshow**: Responsive slide carousel featuring field equipment, real statistics, CTAs, and background gradient mesh overlays.
3. **Interactive Carousels**:
   - **Verified Field Deployments**: Real field operations (Eat 'N' GO delivery bikes, Caterpillar generators, cold storage racks, HVAC units).
   - **Tag Materials & Substrates**: Production samples (Dangote Sugar Refinery, United Bank for Africa, US Government, Lagos State LMDGP, CVCNU) with click-to-zoom label inspector modal.
4. **On-Site Field Video Showcase**: Embedded responsive video player with custom play/pause and mute/unmute controls.
5. **Interactive Quote & Cost Calculator**: Multi-step estimator allowing clients to configure asset volumes (50 to 10,000+), branch count, label substrates, and symbology, outputting directly to formatted email.
6. **Mobile-First & Ultra Fast**: Pure CSS Modules, zero heavy external runtime libraries, optimized WebP imagery, pre-rendered static routes.
7. **Netlify Deployment Ready**: Includes pre-configured `netlify.toml`.

## 💻 How to Run Locally

### 1. Prerequisites
- Node.js (v18.17+ or v20+)
- npm or yarn

### 2. Installation
Open your terminal in the project directory:
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
npm run start
```
